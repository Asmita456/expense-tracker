
# Expense Tracker

## Project Description
Expense Tracker is a simple Python-based application that helps users record, view, filter, and manage their daily expenses. It stores expense data in a JSON file without requiring a database.

## Features
- Add new expenses
- View all expenses
- Calculate total and average expenses
- View category-wise expense summaries
- Filter expenses by category
- Delete expenses
- Save data in a JSON file

## Technologies Used
- Python
- JSON
- Visual Studio Code

## Requirements
- Python 3 installed
- Visual Studio Code or any text editor

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

   `python main.py`

## Data Storage
Expense records are stored in `expenses.json`. The data remains available after the program is closed and restarted.
